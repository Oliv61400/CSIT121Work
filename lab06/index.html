LAB 5

By Lester Oliva

Best design practices help make websites that work well for everyone. Good design is not just about looking good, it is about making the page easy to use, read and accessible across different devices and for diffrent people

Things I have learned about design practices

  1. Use semantic HTML so the structures of the page makes sense. Headings, list add sections should be used correctly.
  2. Making sure text has good contrast with the background so it is easy to read. Try not to rely only on color to share information.
  3. Design mobile first and use media queries so the layout works on smaller screens and large ones.
  4. Keep layout simple and consistent. White spaces and clear headings help people scan the page

Conclusion

Following best design practices makes a webpage more professional and easier for people to use. I plan to keep these ideas in mind as i progress and build more pages in this course.
